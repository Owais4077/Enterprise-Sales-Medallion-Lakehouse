# Data sources (plan; implemented in Phase 2)

All data is **synthetic**, generated by `data_generation/` with a fixed random seed, so every
run is reproducible and nothing is private or copyrighted.

| Dataset | Source system | Approx. rows | Notes |
|---|---|---|---|
| customers | PostgreSQL | 5,000 | Has `updated_at`; some records updated after creation |
| products | PostgreSQL | 200 | Categories, price, cost |
| orders | PostgreSQL | 50,000 | Spread over ~2 years, statuses, `updated_at` |
| order_items | PostgreSQL | 150,000 | FK to orders and products |
| payments | PostgreSQL | 50,000 | Method, status, amount |
| countries | CSV file | ~50 | Reference data, ISO codes, region |
| exchange_rates | REST API | daily x currencies | Paged, `updated_since` filter |
| supplemental events | JSON file | small | Demonstrates JSON ingestion |

Deliberate data-quality defects (duplicates, nulls, negative amounts, bad dates, orphan keys)
are injected at a small, configurable rate so the Silver quarantine and DQ checks have real
work to do.

Row counts are targets; the final numbers are documented when Phase 2 is complete.
